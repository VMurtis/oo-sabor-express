# 🍽️ OO Sabor Express

Projeto desenvolvido em **Python** utilizando **Programacao Orientada a Objetos (POO)**.

O objetivo do projeto é criar um sistema de gerenciamento de restaurantes, permitindo cadastrar restaurantes, alterar seu status, receber avaliacoes de clientes e calcular a media das notas recebidas.

---

## 🚀 Tecnologias utilizadas

- Python 3
- Programacao Orientada a Objetos
- Git e GitHub

---

## 📚 Conceitos de POO aplicados

Neste projeto foram praticados:

- Classes e objetos
- Construtor (`__init__`)
- Atributos de instancia
- Encapsulamento
- Propriedades (`@property`)
- Metodos de classe (`@classmethod`)
- Composicao entre classes
- Lista de objetos
- Validacao de dados
